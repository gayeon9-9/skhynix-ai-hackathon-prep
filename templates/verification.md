# 검증 기록

> 실제 실행한 검사의 입력과 결과를 적습니다. 실행하지 못한 항목은 그 이유를 남깁니다.

| 요구사항 | 검사 입력·상황 | 기대 결과 | 실제 결과 | 실행 명령·확인 근거 | 상태 |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

## 필요한 항목만 선택

- 정상 입력에서 핵심 기능이 동작하는가?
- 빈 입력·없는 파일·잘못된 형식은 어떻게 처리하는가?
- 결측·중복·식별키 오류를 놓치지 않는가?
- 날짜·단위·분모·합계가 정의와 맞는가?
- 작은 표본을 직접 계산한 결과와 같은가?
- 원본 파일을 의도치 않게 바꾸지 않았는가?
- 실행 방법이 다른 사람이 따라 할 수 있을 정도로 설명되어 있는가?
- 모델 평가가 있다면 예측 시점에 알 수 없는 정보나 평가 데이터가 학습에 섞이지 않았는가?
