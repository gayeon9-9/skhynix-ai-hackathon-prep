# 준비 자료를 활용하는 순서

이 문서는 일반적인 학습·참고 순서입니다. 특정 시험의 공식 안내나 제출 양식이 아니며, 실제 과제의 README와 운영 규칙을 우선합니다.

## 1. 먼저 확인할 다섯 가지

| 질문 | 적을 내용 |
| --- | --- |
| 누구의 어떤 문제인가? | 사용자가 현재 하는 일과 겪는 불편 |
| 최종적으로 무엇을 제출해야 하는가? | 결과물 종류, 필수 파일명, 실행·검증 방법 |
| 어떤 자료를 사용할 수 있는가? | 제공 데이터, 문서, 허용된 공개 자료 |
| 성공을 어떻게 판단하는가? | 정확성, 동작, 시간, 누락률 등 과제에서 요구한 기준 |
| 모르는 것은 무엇인가? | 추가 질문이 필요한 사실과 임시로 둔 가정 |

문제가 데이터 분석이라는 이유만으로 예측 모델부터 만들지 않습니다. 집계나 대조만으로 목표를 달성할 수 있는지 먼저 확인합니다. 화면 제작 과제라면 실제로 사용자가 입력하고 결과를 확인하는 핵심 흐름을 먼저 정합니다.

## 2. 필요한 자료만 선택하기

| 현재 상황 | 볼 파일 |
| --- | --- |
| 반도체 용어를 이해해야 함 | `domain/semiconductor_basics.md` |
| 원문 근거가 필요함 | `references/SOURCES.md` |
| CSV 구조·결측·중복을 파악해야 함 | `snippets/profile_csv.py` |
| 두 표가 일치하는지 확인해야 함 | `snippets/compare_csv.py` |
| 구현 범위와 확인할 질문을 정해야 함 | `templates/task_plan.md` |
| 선택 이유와 검증을 남겨야 함 | `templates/decision_log.md`, `templates/verification.md` |

AI에 저장소 전체를 한꺼번에 읽히기보다 목록을 먼저 보여주고 관련 파일만 선택하도록 요청합니다. 원문을 확인할 때도 필요한 범위와 목적을 먼저 정합니다.

## 3. AI에게 요청할 때 포함할 내용

- 작업 목표와 성공 기준
- 확인할 파일 또는 데이터 경로
- 입력과 기대 출력
- 지켜야 할 제약과 유지해야 할 기존 구조
- 실행 후 확인할 결과

예시 요청:

> 제공된 README와 파일 목록을 먼저 확인해 주세요. 목표, 필수 제출물, 제약, 확인이 필요한 정보를 짧게 정리하고 실행할 작업 순서를 제안해 주세요. 확인한 사실과 가정을 구분해 주세요.

> 이 CSV의 구조와 결측·중복 현황을 확인해 주세요. 원본은 수정하지 말고, 실제 식별키와 집계 단위를 결정하기 전에 확인할 질문을 알려주세요.

> 구현한 기능을 요구사항과 대조해 주세요. 실제로 실행한 검사와 실행하지 못한 검사를 나누고, 남은 오류와 한계를 요약해 주세요.

반복해서 전체 결과를 다시 만들기보다, 확인된 문제와 수정할 범위를 지정해 요청합니다. 실행하지 않은 검사나 측정하지 않은 효과를 완료·성과로 적지 않습니다.

## 4. 데이터 도구 실행 전

1. CSV 인코딩, 헤더, 행의 의미를 확인합니다.
2. `001` 같은 식별번호는 숫자로 바꾸면 의미가 달라질 수 있으므로 문자로 유지합니다.
3. 두 표를 대조할 때 키가 유일한지 먼저 확인합니다. 중복키는 임의로 하나만 남기지 않습니다.
4. 값 차이가 오류인지, 정상 변경인지, 단위·기준 차이인지는 업무 정의로 판단합니다.
5. 결측값·이상치를 발견해도 처리 이유를 정하기 전에는 삭제·대체하지 않습니다.

머신러닝이 필요한 과제라면 예측 시점에 알 수 없는 정답 정보가 입력에 들어가지 않도록 확인하고, 평가 데이터가 전처리·모델 선택에 섞이지 않게 구분합니다. 관련 공식 문서는 `references/SOURCES.md`의 scikit-learn 자료를 참고하세요.

## 5. 결과를 설명할 수 있는지 확인

구현 뒤 `guides/SELF_REVIEW.md`의 질문에 자신의 말로 답해 봅니다. 이해하지 못한 부분은 작은 입력 예시를 넣어 실제 동작을 확인합니다.

이 저장소에는 개인 응시 링크, 개인 계정 정보, 비공개 과제 파일, 실제 풀이 결과를 추가하지 않습니다. 시험·평가에서 사용한다면 외부 전송과 AI 사용 범위는 반드시 해당 안내에 맞춥니다.
