# 자기 설명 연습

실제 시험 문항을 예상하거나 복제한 문서가 아닙니다. 작업을 마친 뒤 본인이 선택한 방법과 검증 결과를 설명하는 연습용입니다.

가능하면 AI 없이 질문 하나당 3~5문장으로 설명해 봅니다. 모르는 내용은 아는 것처럼 쓰지 않고, 확인이 필요한 점을 구분합니다.

## 연습 질문

1. 해결하려던 문제와 결과의 성공 기준은 무엇인가요?
2. 여러 방법 중 지금 방법을 선택한 이유는 무엇인가요?
3. 사용한 자료·코드에서 직접 이해하고 바꾼 부분은 무엇인가요?
4. AI의 제안을 어떤 근거로 받아들이거나 수정했나요?
5. 결과가 맞는지 어떤 입력과 기준으로 확인했나요?
6. 남은 한계와 추가 시간이 있다면 먼저 개선할 부분은 무엇인가요?

## 답변을 점검하는 기준

- 실제 파일·함수·데이터와 설명이 일치하는가?
- 선택한 이유가 목표와 제약에 연결되는가?
- 확인한 결과와 기대만 하는 효과를 구분했는가?
- 사용하지 않은 기술이나 실행하지 않은 테스트를 적지 않았는가?
- 자료를 가져온 부분과 직접 판단·수정한 부분이 분명한가?
- 질문의 전제가 실제 작업과 다르면 차이를 설명했는가?

## 설명 연습 예시

상황: 두 CSV의 검사기록별 수량이 같은지 확인하는 작은 과제.

- 목표: 두 파일에서 누락된 검사기록과 수량이 다른 검사기록을 찾는다.
- 판단: 검사기록 식별키인 `inspection_id`를 문자로 유지해 `0001`과 `1`을 구분한다. 하나의 로트에 검사기록이 여러 개 있을 수 있으므로 `lot_id`만으로 연결하지 않는다.
- 검증: 값 변경·행 누락·행 추가가 있는 합성 예제로 대조 도구를 실행한다.
- 한계: 도구가 찾는 것은 파일 사이의 차이이며, 실제 업무상 오류 여부는 원자료와 담당자의 확인이 필요하다.

위 예시는 설명 구조를 익히기 위한 것입니다. 실제 답변에는 본인이 한 작업만 적습니다.
