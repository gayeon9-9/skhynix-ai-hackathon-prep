# 작은 CSV 도구 연습

이 폴더의 CSV 두 개는 이 저장소를 위해 직접 만든 **합성 예제**입니다.
실제 반도체 공정 데이터, 회사 자료, 시험 제공 데이터가 아닙니다.
온도 등 수치에는 공정상 의미를 부여하지 않았습니다. 데이터 확인 방법만 연습하세요.

## 실행

저장소 최상위 폴더에서 Python 3.10 이상으로 실행합니다. 패키지 설치는 필요 없습니다.

```bash
python3 snippets/profile_csv.py examples/inspection_before.csv
python3 snippets/compare_csv.py examples/inspection_before.csv examples/inspection_after.csv --key inspection_id
python3 -m unittest discover -s tests -v
```

두 번째 명령은 차이가 있으므로 **종료 코드 1**을 반환합니다. 코드 오류가 아닙니다.
일치하면 0, 입력 형식 또는 키 오류가 있으면 2입니다. 입력 오류 설명은 표준 오류(stderr)에 나옵니다.

## 기대 결과

- `profile_csv.py`: 5행, 7열, 완전히 중복된 행 0개, `temperature_c`의 결측 후보 2개.
- `compare_csv.py`: 기준 파일에만 `0004`, 비교 파일에만 `0006`이 있습니다.
- `0002`의 온도와 상태, `0003`의 불량 수가 다릅니다.
- 식별번호 `0001`의 앞쪽 0은 보존됩니다.

## 처리 기준과 한계

- 모든 파일은 UTF-8 또는 UTF-8 BOM CSV여야 합니다. 다른 인코딩은 별도로 확인하세요.
- CSV 전체를 메모리로 읽으므로 작은 연습 파일용입니다. 대용량 처리 도구가 아닙니다.
- 헤더의 빈 이름·중복 이름, 행마다 다른 열 개수는 오류로 알립니다. 빈 줄도 열 개수가 맞지 않으면 오류입니다.
- 비교할 두 파일의 열 이름 집합은 같아야 합니다. 열 순서가 다른 것은 허용합니다.
- 키는 원문 문자열을 사용합니다. `0001`과 `1`, `A`와 ` A`는 서로 다른 키입니다.
- 비교에서는 빈 값·공백·`1`과 `1.0`도 서로 다르게 취급합니다. 업무상 같은 값으로 볼지는 별도 결정이 필요합니다.
- 복합키는 `--key lot_id machine_id`처럼 지정합니다. 선택한 조합이 중복되거나 비어 있으면 오류로 중단합니다.
- 프로파일의 빈 문자열·NA·N/A·NULL·NONE·NaN은 대소문자와 양끝 공백을 제외하고 결측 **후보**로 셉니다. 실제 코드값인지는 사람이 판단합니다.
- 수치 요약은 관측값이 모두 유한한 숫자로 읽힐 때만 표시하며, 식별번호에도 나타날 수 있습니다. 원본 타입을 바꾸지 않습니다.
- 수치 요약은 부동소수점 근사값입니다. 금액 정산에는 별도의 정확한 계산 기준을 사용하세요.
- 원본 파일을 고치거나 데이터를 자동으로 삭제·보정하지 않습니다. 결과는 화면의 JSON으로만 출력합니다.
- 필요하면 결과를 `> report.json`으로 저장할 수 있지만, **원본 CSV와 다른 새 경로**를 사용하세요. 셸 리다이렉션은 기존 파일을 덮어쓸 수 있습니다.
