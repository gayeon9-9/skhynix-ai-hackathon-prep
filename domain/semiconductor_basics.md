# 반도체 용어와 데이터 읽기

공개 입문자료를 바탕으로 직접 작성한 학습 메모다. 특정 과제의 출제 범위나 정답을 뜻하지 않는다.
실제 분석에서는 제공된 데이터 사전, 업무 기준, 요구사항을 먼저 따른다.
확인일: 2026-10-30. 출처의 원문·그림·코드를 복제하지 않았다.

## 1. 생산 단위부터 구분하기

| 용어 | 쉽게 이해하기 | 데이터를 볼 때 확인할 것 |
|---|---|---|
| 웨이퍼, wafer | 여러 칩의 회로를 만드는 얇은 기판 | 웨이퍼 한 장인지, 그 위의 개별 칩인지 |
| 다이, die | 웨이퍼 위에서 하나의 회로를 이루는 개별 칩 단위 | 같은 다이에 검사 기록이 여러 개 있는지 |
| 로트, lot | 제조 과정에서 함께 처리·관리하는 웨이퍼 묶음 | 로트와 웨이퍼 ID의 관계, 묶음의 실제 크기 |
| 공정, process | 막을 입히거나 깎는 등 제품을 만드는 작업 단계 | 공정명과 작업 순서, 시작·종료 시점 |
| 장비, tool/equipment | 공정을 수행하는 기계 | 장비 ID, 작업 시점, 대상 제품 |
| 레시피, recipe | 온도·압력 등 특정 공정에 적용하는 설정 묶음 | 레시피 ID와 변경 이력, 측정값과 설정값의 구분 |
| 검사, test/inspection | 정해진 기준으로 상태나 품질을 확인하는 과정 | 검사 단계, 판정 기준, 재검사 여부 |

웨이퍼·다이·검사는 [S02](../references/SOURCES.md#s02), 로트·장비·레시피는 [S07](../references/SOURCES.md#s07)을 참고했다.
한 행이 다이 하나인지, 검사 한 번인지 먼저 확인한다. 행 수를 곧바로 생산량으로 쓰면 안 된다.
로트의 장수나 ID의 유일성은 추정하지 말고 데이터 설명과 실제 중복을 확인한다.

## 2. DRAM, NAND, HBM

| 용어 | 역할을 중심으로 이해하기 |
|---|---|
| DRAM | 실행 중인 프로그램과 데이터를 다루는 메모리. 전원이 필요하고 저장 상태를 주기적으로 새로 유지한다. |
| NAND flash | 전원이 꺼져도 데이터를 보관하는 메모리. SSD 등 저장장치에 쓰인다. |
| HBM | 여러 DRAM 칩을 쌓고 연결해 많은 데이터를 빠르게 전달하도록 만든 고대역폭 메모리. |
| TSV | 쌓인 칩 사이의 신호 전달에 쓰는 수직 연결 기술. HBM 구조를 이해할 때 만나는 용어. |

기본 개념 출처: [S01](../references/SOURCES.md#s01).
이 문서는 제품 세대, 시장점유율, 최신 사양을 정리하지 않는다. 2024년 설명을 현재 제품 순위로 해석하지 않는다.

## 3. 8대 공정을 한 문장씩

입문용 분류다. 실제 제조는 여러 작업의 반복과 세부 단계로 구성된다.

| 공정 | 핵심 역할 |
|---|---|
| 웨이퍼 제조 | 회로를 만들 기판을 준비한다. |
| 산화 | 웨이퍼 표면에 산화막을 만든다. |
| 포토 | 빛을 이용해 회로 패턴을 옮긴다. |
| 식각 | 필요한 패턴을 남기도록 일부 물질을 제거한다. |
| 증착·이온주입 | 얇은 막을 만들거나 전기적 특성을 조절한다. |
| 금속 배선 | 회로의 구성 요소를 전기적으로 연결한다. |
| EDS | 웨이퍼 상태에서 칩의 전기적 특성과 양품 여부를 검사한다. |
| 패키징 | 칩을 외부와 연결하고 보호하는 형태로 만든다. |

분류와 설명의 참고 자료: [S02](../references/SOURCES.md#s02).
분석에서는 공정 이름만으로 원인을 정하지 않는다. 같은 제품·단계·기간인지 함께 확인한다.

## 4. 수율과 불량률: 분모를 먼저 적기

수율은 양품 비율을 뜻하지만, 생산·검사 단계에 따라 계산 대상이 달라질 수 있다.
[S02](../references/SOURCES.md#s02)의 EDS 설명은 웨이퍼의 칩 개수를 기준으로 설명한다.
아래 표는 **판정이 끝난 개별 다이**를 대상으로 정한 연습용 정의다.

| 지표 | 이 연습에서의 계산 |
|---|---|
| 검사 기준 수율 | 합격 다이 수 ÷ 판정 완료 다이 수 × 100 |
| 검사 기준 불량률 | 불합격 다이 수 ÷ 판정 완료 다이 수 × 100 |

직접 만든 예: 판정 완료 1,000개 중 합격 950개, 불합격 50개라면 각각 95%, 5%다.
이처럼 같은 분모를 합격·불합격이 빠짐없이 나눌 때만 두 비율의 합이 100%가 된다.

- 미검사·보류·재검사 건을 어떻게 처리했는지 적는다.
- 웨이퍼 수, 다이 수, 검사 횟수를 같은 분모에 섞지 않는다.
- 한 제품에 결함이 여러 개 있어도 불량 제품 수는 한 개일 수 있다. 결함 건수와 구분한다.
- 그룹별 비율을 합칠 때는 분자와 분모를 각각 더해 다시 계산한다.
- 95%에서 97%가 되면 2%p 상승이다. 상대 증가율과 구분한다.

## 5. 문제 유형별 첫 질문

아래 질문은 자료를 적용하기 위해 직접 만든 점검 항목이다.

| 상황 | 먼저 물을 것 | 작게 만들 수 있는 첫 결과 |
|---|---|---|
| 두 표가 맞지 않음 | 같은 대상을 어떤 키로 연결하는가? | 한쪽에만 있는 ID와 값 차이 목록 |
| 불량이 늘어남 | 언제부터, 어떤 제품·단계에서 늘었는가? | 기간·제품별 분모와 불량률 표 |
| 처리가 늦어짐 | 기다린 시간과 실제 작업 시간이 구분되는가? | 단계별 소요 시간과 지연 건 목록 |
| 문서가 흩어져 있음 | 질문에 필요한 근거가 어느 문서·부분에 있는가? | 출처 위치가 붙은 근거 목록 |
| 예측이 필요함 | 예측 시점에 실제로 알 수 있는 입력인가? | 기준 성능과 검증 방법을 적은 표 |

표 대조에서는 합치기 전후 행 수와 중복을 확인한다. 키의 관계에 맞는 `merge` 검증과 누락 표시를 참고할 수 있다. [S05](../references/SOURCES.md#s05)
문서 답변에서는 확인된 사실, 해석, 아직 모르는 내용을 나누어 쓴다. 근거 없는 내용을 채우지 않는다.

## 6. 해석과 검증에서 놓치기 쉬운 것

- **상관관계는 원인의 증명이 아니다.** 제품 종류나 작업 시점 같은 다른 차이도 살핀다.
- **이상치는 곧 불량이 아니다.** 입력 오류, 드문 정상 사례, 실제 이상 가능성을 구분한다.
- **결측은 0이 아니다.** 미측정·수집 실패·해당 없음 가운데 무엇인지 확인한다.
- **중복 행은 곧 오류가 아니다.** 재검사나 여러 공정 기록일 수 있으므로 의미를 확인한다.
- **예측에 정답 정보를 섞지 않는다.** 예측 시점 이후의 결과를 입력하면 성능이 과장될 수 있다.
- 학습·평가 자료를 먼저 나눈 뒤, 결측 대체와 표준화의 기준은 학습 자료에서만 배운다. [S06](../references/SOURCES.md#s06)
- 평가 결과와 현업 적용 효과를 구분한다. 연습 결과를 실제 비용 절감이나 수율 개선으로 보고하지 않는다.

## 7. 연습 자료를 고르는 법

- **처음에는 AI4I**: 의미가 적힌 제조 관련 열로 읽기·집계·검증을 연습한다. 합성 데이터다. [S03](../references/SOURCES.md#s03)
- **추가 연습은 SECOM**: 결측과 드문 실패가 있는 반도체 제조 데이터를 다룬다. 최신 HBM 자료는 아니다. [S04](../references/SOURCES.md#s04)
- 데이터 원본은 이 저장소에 포함하지 않는다. 필요하면 출처에서 이용 조건을 확인한다.
- 분야가 정해지지 않았다면 특정 모델보다 데이터 확인, 표 대조, 근거 정리, 결과 검증부터 연습한다.
